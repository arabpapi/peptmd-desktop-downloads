# PeptMD Desktop downloads

Official Windows desktop installer downloads for PeptMD.

Installers are published in this repository's Releases. The application connects to your authorized PeptMD clinic website. This repository contains distribution information and installer assets only; application source code, credentials, and patient data are not published here.

Current installers are unsigned and may show Windows publisher warnings. Installation requires agreement to the displayed PeptMD Desktop Application Terms. Desktop update notifications may direct you to download a newer installer; unsigned builds do not silently install updates.

Use https://peptmd.com/download for the current installer once a release is published.
